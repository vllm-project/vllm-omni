## Purpose

Split the monolithic `tests/helpers/runtime.py` so request clients live in `tests/helpers/client.py` and env/device cleanup lives in `tests/helpers/clean.py`. Stop star-importing from `tests.helpers`, and point e2e/reliability call sites at `OnlineOmniClient` / `OfflineOmniClient` (legacy aliases kept). `tests/conftest.py` stays a pytest-plugin entrypoint only — no lazy re-exports.

Also in this change:

- Diffusion online determinism and multi-output checks
- TTS coverage consolidation (including moving the Qwen3-TTS Base async-chunk / ref-audio artifact cases into `test_qwen3_tts_base_expansion.py`)
- Close stage-CLI log handles on teardown (`VLLM_OMNI_KEEP_LOG` keeps files)
- Rollback launched stage processes / log FDs when `OmniServer.__enter__` fails, and run `OmniRunner` teardown if `Omni(...)` construction fails (Python does not call `__exit__` in either case)
- New-schema deploy overlay handling in stage config
- ComfyUI e2e uses `get_open_port()` instead of pytest-asyncio `unused_tcp_port_factory`; engine stage-init test pins the `CUDA_VISIBLE_DEVICES` mapping
- Keep `get_distributed_init_method()` as the public helper name (optional `prefix`)
- Carry forward main's xdist fixture, CosyVoice3 ROCm request timeout, and Qwen3-Omni prefix-cache `multimodal_tokens` check

### Coverage note (EngineDeadError / #5049)

`test_xvector_then_icl_same_ref_audio_keeps_engine_alive` (x-vector → ICL on the same `ref_audio`, the EngineDeadError regression from #5049) now lives in `tests/e2e/online_serving/test_qwen3_tts_base_expansion.py` with module mark `full_model` + `tts`.

**Ready no longer covers this case.** Ready only runs `tests/e2e/online_serving/test_qwen3_tts_base.py` at `core_model`. The regression is exercised on **nightly** (`full_model and L4 and tts` in `.buildkite/cuda/test-nightly.yml`), not on ready/merge. This PR does not move that test back onto `core_model`.
